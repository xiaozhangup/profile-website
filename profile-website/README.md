# profile-website

基于原有白底、蓝色代码选区与绿色 ASCII 视觉的静态个人主页。

## 预览与维护

直接打开 `index.html`，或使用静态 HTTP 服务预览。基本资料与项目详情在 `script.js`，可见正文与项目卡片在 `index.html`，样式在 `styles.css`。

精选项目按 Octopus、LyricifyIsland、xiaozhangup-bot 排列。技术栈结合个人 GitHub README 与桌面开发项目整理。头像通过 GitHub 头像地址加载，需要联网；其余页面样式及交互无需外部依赖。联系入口为 GitHub，没有示例邮箱和访客头像上传。

修改后运行 `python build-standalone.py` 同步父目录的单文件版本 `profile-website.html`；单文件版仍通过网络加载 GitHub 头像。

## 章节浏览

- 桌面端每章占满一屏，标题、主体和页尾按可用高度弹性布局，保持文字原始大小；滚轮、方向键、Page Up / Page Down、Home / End 和页内链接使用相同的定位逻辑。
- 标题、正文、项目卡片和代码装饰按滚动方向分组进出；系统开启“减少动态效果”时直接切换。
- 切换会同步网址锚点，刷新和调整窗口大小后保持当前章节。
- 手机端保持文字可读，长内容在当前章节内滚动，到达边缘后继续滑动切换章节。

## 装饰动画

- 首页代码色带整行从上到下依次展开，每行间隔 25 毫秒，约 0.6 秒完成；不使用逐字打字机效果。
- 进入动画：每次进入章节，分隔线展开、头像角标淡入、ASCII 与项目图形轻微上移显现，约 0.7 秒后结束。
- 持续动画：星号与项目轨道缓慢旋转，状态点和首页短横条轻微呼吸；离开章节或页面切到后台时暂停。
- 代码色带、头像、ASCII、项目图形与联系星号以 6–8 秒周期上下浮动，幅度为 ±3–5px，章节入场后错峰启动；头像悬停或获得键盘焦点时暂停。手机端幅度减半。
- 系统开启“减少动态效果”时关闭上述动画。单文件版本同步包含这些效果。

章节切换时，目标页的入场、打字机和装饰动画统一在滚动距离达到约 80% 后启动，持续动画也在此时恢复。
